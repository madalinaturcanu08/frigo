# Family pilot — study plan (not yet carried out)

**Goal:** measure, instead of assume, how much food and money Frigo helps a family save (replaces the 25 % / 35 %
scenarios in `docs/ECONOMICS.md`).

| | |
|---|---|
| Participants | 5–10 households (classmates' families), each gives informed consent; a parent agrees for under-18s |
| Length | 2 weeks **before** Frigo (baseline) + 2 weeks **with** Frigo |
| Baseline | Each family writes down every food item they throw away (what, roughly how much, why) on a paper form |
| With Frigo | Families add their food to Frigo and tap *Used it* / *Tossed*; reminders on |
| Measured | items thrown away per week, kg (estimated) and lei thrown away, % of items eaten in time, the number of days used |
| Privacy | Each family gets a code (Family 1, 2…). No names, emails or receipts leave the families; only counts are collected |
| Analysis | Compare baseline vs with-Frigo per family (paired comparison); report the median change and the range, not just the average; with < 10 families the result is a case study, not proof |
| Feedback | 5 short questions at the end (what was useful, what was annoying, would you keep using it) |

**Limits to state:** small sample, families who volunteer are probably more motivated, writing things down by itself
changes behaviour (the baseline may already be lower than usual).
